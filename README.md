## نظرة عامة

نظام **كنوال المالي** هو تطبيق ويب محلي مبني خصيصًا لإدارة الشؤون المالية لشركة أسطول شاحنات صغيرة إلى متوسطة. يجمع النظام بيانات الشاحنات والموظفين والمداخيل والمصروفات والرواتب في مكان واحد، ويوفّر تقارير مالية تفصيلية (قائمة الدخل) قابلة للتصدير بصيغتي PDF و Excel.

النظام مصمّم للعمل **محليًا فقط** على جهاز الكمبيوتر باستخدام قاعدة بيانات SQLite، بدون الحاجة إلى خادم قاعدة بيانات منفصل أو اتصال بالإنترنت. واجهته بالكامل بالعربية (RTL) مع دعم كامل للوضع الفاتح والداكن.

## المميزات الرئيسية

### إدارة الشاحنات
- إضافة وتعديل وحذف شاحنات (رقم اللوحة، الموديل، سنة الصنع، تاريخ وقيمة الشراء)
- تتبع حالة كل شاحنة: **تعمل** | **صيانة** | **متوقفة**
- تعيين سائقين للشاحنات مع تاريخ بدء وانتهاء
- عرض تفصيلي لكل شاحنة مع ملخص المداخيل والمصروفات المرتبطة بها
- عرضين: **جدول** و **كيانات (Kanban)**

### إدارة الموظفين والرواتب
- إضافة وتعديل وحذف موظفين (اسم، وظيفة، نوع الراتب، الراتب الأساسي، رقم الهاتف)
-三种 أنواع رواتب: **ثابت شهري** | **بالرحلة** | **نسبة من الإيراد**
- إنشاء كشوف رواتب شهرية مع حساب تلقائي: الصافي = الأساسي − الخصومات − السلف
- تتبع حالة الدفع (مدفوع / غير مدفوع)
- قيود فريدة تمنع تكرار راتب الموظف في نفس الشهر
- تعبئة تلقائية للراتب الأساسي عند اختيار الموظف

### إدارة المداخيل
- تسجيل إيرادات لكل شاحنة مع تاريخ، اسم العميل، الوجهة، ونوع الإيراد
- أنواع الإيرادات: **أجرة نقل** | **عقد شهري ثابت** | **إيجار شاحنة**
- عرض إجمالي الإيرادات لكل شاحنة

### إدارة المصروفات
- تسجيل مصروفات عامة أو مرتبطة بشاحنة محددة
- تصنيف المصروفات عبر فئات ديناميكية (صيانة، وقود، إلخ)
- وصف تفصيلي لكل مصروف

### التقارير المالية
- **قائمة الدخل التفصيلية**: إجمالي الإيرادات والمصروفات المباشرة والمصاريف العامة والرواتب وصافي الربح
- تصفية حسب الفترة (من/إلى)
- تصدير التقرير بصيغة **PDF** (باستخدام Puppeteer وخط Tajawal العربي المدمج)
- تصدير التقرير بصيغة **Excel** (باستخدام ExcelJS بتنسيق احترافي)
- **طباعة مباشرة** من المتصفح

### الهوية والتصميم
- تسجيل دخول وخروج مع جلسات آمنة
- واجهة عربية بالكامل (RTL) بتصميم حديث
- **وضع فاتح وداكن** مع تبديل فوري وحفظ التفضيل
- ألوان مخصصة للنظام (لون رئيسي، لون ثانوي، لون مميز) قابلة للتعديل من الإعدادات
- خطوط عربية مدمجة: **Cairo** للواجهة و **Tajawal** للتقارير المطبوعة

### الأمان
- تشفير كلمات المرور بخوارزمية **scrypt** المدمجة في Node.js (بدون مكتبات خارجية)
- جلسات موقّعة بـ **HMAC SHA-256** عبر Web Crypto (تعمل في بيئة Node و Edge)
- حماية جميع الصفحات عبر Middleware (إلا صفحات الدخول والتقارير)
- آمن.timing-safe مقارنة كلمات المرور لمنع هجمات التوقيت

### سجل النشاط
- تسجيل تلقائي لكل عملية إضافة / تعديل / حذف عبر Prisma Middleware
- تتبع نوع العملية والكيان والبيانات المرتبطة
- تسجيل عمليات التصدير والاستيراد

### النسخ الاحتياطي
- تصدير كامل لبيانات النظام بصيغة **JSON**
- استيراد نسخة احتياطية مع استبدال جميع البيانات عبر معاملة (transaction)
- تسجيل عمليات النسخ الاحتياطي في سجل النشاط

### البحث
- بحث شامل عبر جميع الكيانات: شاحنات، موظفين، مداخيل، مصروفات، رواتب
- نتائج منظمة حسب الكيان مع روابط مباشرة

### تدفق البيانات

```
┌─────────────────────────────────────────────────────────────┐
│                     واجهة المستخدم (React)                   │
│  Server Components ←→ Client Components (use "use client")   │
└────────────────────────────┬────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────┐
│                    Server Actions / API Routes               │
│          src/app/(app)/*/actions.ts  ←→  src/app/api/*      │
└────────────────────────────┬────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────┐
│                     Prisma ORM (Client)                     │
│  prisma.ts — PrismaClient + middleware (Activity Log)       │
└────────────────────────────┬────────────────────────────────┘
                             │
┌────────────────────────────▼────────────────────────────────┐
│               SQLite Database (dev.db)                      │
│  PrismaLibSql Adapter (libsql WASM)                        │
└─────────────────────────────────────────────────────────────┘
```

- **Server Components**: تجلب البيانات مباشرة من قاعدة البيانات عبر `prisma` وتعيد JSX
- **Server Actions**: الدوال المعرفة في `actions.ts` تُنفَّذ على الخادم وتتفاعل مع قاعدة البيانات
- **API Routes**: مخصصة للعمليات الخاصة (تسجيل الدخول، تصدير PDF/Excel، النسخ الاحتياطي، فحص الصحة)
- **Middleware**: يتحقق من الجلسة في كل طلب ويُعيد التوجيه إلى صفحة الدخول إذا لم تكن هناك جلسة صالحة

### ملاحظات تقنية مهمة

- **المبالغ المالية**: تُخزَّن كأعداد صحيحة بأصغر وحدة عملة (القرش = 1/100). مثلاً: `123456` = `1234.56 د.إ`. جميع الحسابات تتم عبر `decimal.js`.
- **الحذف الناعم (Soft Delete)**: جميع الكيانات تدعم الحذف الناعم عبر حقل `deletedAt` بدلاً من الحذف الفعلي.
- **الفهرسة**: تم وضع فهرس على الحقول المُستخدمة بكثرة في الاستعلامات (`truckId`, `date`, `month`, `deletedAt`, `status`).
- **القيود الفريدة**: `@@unique([employeeId, month])` في جدول `Payroll` يمنع تكرار راتب موظف في نفس الشهر.

## قواعد ومبادئ هندسية اتبعناها

1. **الدقة المالية المطلقة**: استخدام `decimal.js` في جميع الحسابات المالية وتخزين المبالغ كأعداد صحيحة بالقرش لتفادي أخطاء الأرقام العشرية الشائعة في JavaScript.

2. **الحذف الناعم بدل الحذف الفعلي**: جميع الكيانات تدعم `deletedAt` لضمان عدم فقدان البيانات وتمكين التراجع عن الحذف.

3. **تسجيل نشاط تلقائي (Audit Log)**: Prisma Middleware يسجل تلقائيًا كل عملية تعديل على أي كيان في جدول `ActivityLog`، مع استثناء جدول السجل نفسه لتفادي التكرار اللانهائي.

4. **فصل الحسابات عن واجهة العرض**: جميع الحسابات المالية تتم في `src/lib/money.ts` و `src/lib/compute-reports.ts` بشكل منفصل عن المكونات، مما يسهل الاختبار والصيانة.

5. **الأمان بالتصميم**: تشفير كلمات المرور عبر `scrypt` (بدون مكتبات خارجية)، جلسات موقّعة بـ HMAC مع انتهاء صلاحية تلقائي (7 أيام)، حماية المسارات عبر Middleware.

6. **بدون اعتمادات سحابية**: النظام يعمل محليًا بالكامل مع SQLite عبر WASM. لا يحتاج اتصال إنترنت أو خادم قاعدة بيانات أو حسابات سحابية.

7. **تجربة مستخدم عربية أصيلة**: واجهة RTL بالكامل، خطوط عربية مدمجة، ألوان قابلة للتخصيص، ووضع داكن يحترم تفضيلات المستخدم مع حماية من الوميض.

## طريقة التشغيل محليًا

### المتطلبات

- **Node.js** 24.14.0 (أو أي إصدار يدعم ES Modules)
- **npm** (أو yarn / pnpm)
- نظام تشغيل يدعم `file:` URI لقاعدة البيانات (Windows / macOS / Linux)

### خطوات التنصيب

```bash
# 1. استنساخ المشروع
git clone <repository-url>
cd kanwan

# 2. تثبيت التبعيات
npm install

# 3. إعداد ملف البيئة
cp .env.example .env
# أو أنشئ ملف .env يدويًا واملأه كما في المثال أدناه

# 4. تشغيل تخطيط قاعدة البيانات
npx prisma generate
npx prisma db push

# 5. (اختياري) بذر بيانات تجريبية
# يُنشئ 10 شاحنات، 11 موظفًا، وبيانات مالية متنوعة
node seed-demo.mjs

# 6. تشغيل الخادم المحلي
npm run dev
```

**الآن افتح المتصفح على:** `http://localhost:3000`

### بيانات الدخول الافتراضية

| اسم المستخدم | كلمة المرور |
|:---:|:---:|
| `admin` | `admin123` |

> **⚠️ تنبيه أمني:** يجب تغيير كلمة المرور الافتراضية فور أول استخدام حقيقي. يمكن تغييرها من صفحة الإعدادات.

## متغيرات البيئة

أنشئ ملف `.env` في جذر المشروع بالمتغيرات التالية:

| المتغير | الوصف | القيمة الافتراضية |
|---------|-------|:-----------------:|
| `DATABASE_URL` | مسار ملف قاعدة البيانات SQLite | `file:./dev.db` |
| `AUTH_SECRET` | سر توقيع جلسات HMAC (≥ 32 حرفًا) | *(مطلوب في الإنتاج)* |

### مثال على ملف `.env`

```env
DATABASE_URL="file:./dev.db"
AUTH_SECRET="a-random-secret-string-at-least-32-characters-long"
```

## الأمان

- **تشفير كلمات المرور**: تُشفَّر عبر خوارزمية `scrypt` المدمجة في Node.js مع ملح عشوائي (salt) فريد لكل كلمة مرور. لا تُخزَّن كلمات المرور النصية أبدًا.

- **الجلسات الموقّعة**: تُولَّد جلسات موقّعة بـ HMAC SHA-256 عبر Web Crypto API. كل جلسة تحتوي على معرّف المستخدم وانتهاء صلاحية (7 أيام). التوقيع يتحقق في كل طلب عبر Middleware.

- **حماية المسارات**: Middleware يتحقق من وجود جلسة صالحة لكل طلب يزيد عن `/login` و `/api/auth/*` و `/api/backup` و `/api/reports/*`. الطلبات غير المُصرَّح لها تُعيد التوجيه إلى صفحة الدخول.

- **مقارنة آمنة (Timing-Safe)**: استخدام `crypto.timingSafeEqual` لمقارنة توقيعات الجلسات وتجزئات كلمات المرور، مما يمنع هجمات التوقيت侧信道.

- **HTTP-Only Cookies**: تُخزَّن الجلسة في ملف تعريف ارتباط `httpOnly` مع `sameSite=lax` و `secure` في بيئة الإنتاج.

## ملاحظة ختامية

> نظام **كنوال المالي** مبني خصيصًا لشركة كنوال لإدارة أسطول شاحنات محلية. النظام مصمّم للعمل **محليًا فقط** باستخدام SQLite بدون أي اعتماد على خدمات سحابية أو خوادم خارجية.
>
> مع ذلك، تم تصميمه ليكون **قابلًا للتوسع مستقبلاً**:
> - **مستخدمون متعددون**: يُمكن إضافة نظام صلاحيات (RBAC) عبر جدول `SystemUser` الموجود.
> - **نشر سحابي**: يُمكن ترحيل قاعدة البيانات إلى PostgreSQL أو Turso (libsql cloud) بتحديث بسيط في `prisma.ts` ومتغيرات البيئة.
> - **واجهة برمجية (API)**: جميع العوامل متوفرة بالفعل عبر `src/app/api/`، ويمكن توسيعها لدعم تطبيقات الهاتف أو أنظمة خارجية.
